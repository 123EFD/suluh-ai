This document formally records academic and open-source datasets utilized in the Recommender API knowledge repository.

- **Authors**: Yukai Miao, Yu Bai, Li Chen, Dan Li, Haifeng Sun, Xizheng Wang, Ziqiu Luo, Dapeng Sun, Xiuting Xu, Qi Zhang, Chao Xiang, Xinchi Li (2023)

### 2. GATE Computer Science & Engineering (CSE) Question Dataset
- **Dataset**: `sakshi2409/gate-cse-question-classification-dataset` (Kaggle)
- **Author**: Sakshi (2023)
- **Description**: Graduate Aptitude Test in Engineering (GATE) multi-category examination questions for Computer Science and Engineering, covering Computer Networks, Operating Systems, Mathematics, Algorithms, and Architecture.

---

### 3. StackOverflow C Language Q&A Dataset
- **Dataset**: `Mxode/StackOverflow-QA-C-Language-40k` (Hugging Face)
- **Author**: Mxode (2024)
- **Description**: Curated C programming questions, code implementations, memory lifecycle, and debugging insights.

### 4. Operating Systems Concepts (Sanfoundry MCQs)
- **Topic**: Memory Management & Allocation Strategies
- **Reference**: Abraham Silberschatz, Peter B. Galvin, Greg Gagne - *Operating System Concepts* (10th Edition, Wiley).
